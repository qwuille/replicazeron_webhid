# Helldivers 2 macros

These profiles contain the current Helldivers 2 call-in sequences from the
community-maintained Helldivers-2-Stratagem-JSON-Generator v1.0.9 dataset.

The library is divided by in-game directional binding:

- `wasd/` sends W, A, S, and D key taps.
- `arrowkeyes/` sends keyboard arrow-key taps, allowing normal WASD movement
  keys to remain independent.

Both variants use a randomized 50–100 ms delay after each tap. The profiles do
not press or hold the stratagem-menu key; configure that key in the game and
hold or toggle it separately.

Set the game's directional bindings to match the chosen folder. Preview a
profile in WebHID, choose a zero-based macro slot, and install it. The
Replicazeron can store 16 selected macros at once, while these folders remain
the full downloadable library.
