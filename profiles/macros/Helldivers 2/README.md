# Helldivers 2 arrow-key macros

These profiles contain the current Helldivers 2 call-in sequences from the
community-maintained Helldivers-2-Stratagem-JSON-Generator v1.0.9 dataset.

Each direction is sent as a keyboard arrow-key tap with a randomized 50–100 ms
delay after each tap. The profiles do not press or hold the stratagem-menu key;
configure that key in the game and hold or toggle it separately.

The game's directional bindings must be set to the keyboard arrow keys. Preview
a profile in WebHID, choose a zero-based macro slot, and install it. The
Replicazeron can store 16 selected macros at once, while this directory remains
the full downloadable library.
